# bend-merkle-tree

Hash-generic Merkle trees for Bend 2.

## Features

- compile-time swappable pair hash via Bend template arguments;
- perfect binary trees with zero padding;
- capacity-bounded merkleization with checked and direct APIs;
- deterministic zero-subtree roots;
- byte-to-chunk packing and exact 32-byte hex parsing;
- bundled FIPS 180-4 SHA-256 adapter;
- golden vectors generated by an independent Python reference.

## Requirements

- Bend `2.0.34`
- Python `3.10+` for regenerating test vectors
- Clang for native builds

## Install

Pin a release or commit in your project:

```sh
git clone https://github.com/adust09/bend-merkle-tree.git vendor/bend-merkle-tree
git -C vendor/bend-merkle-tree checkout <commit-or-tag>
```

Then import the modules relative to your Bend entry point:

```bend
import Base
import ./vendor/bend-merkle-tree/src/merkle/tree.bend as M
import ./vendor/bend-merkle-tree/src/merkle/sha256.bend as SHA

def root(chunks: List<&2, List<&2, U32>>) -> List<&2, U32>:
  M.tree.merkleize(~SHA.sha256_pair, chunks)

def bounded(chunks: List<&2, List<&2, U32>>, limit: Nat)
  -> Maybe<&2, List<&2, U32>>:
  M.tree.merkleize_limit_checked(~SHA.sha256_pair, chunks, limit)
```

A custom top-level function with type `Chunk -> Chunk -> Chunk` can replace
`SHA.sha256_pair`. Bend templates let the tree invoke that hash at every node
without an affine closure or runtime dispatch.

## API

- `Chunk.pack(bytes)`: split bytes into zero-padded 32-byte chunks.
- `Chunk.from_hex(hex)`: parse exactly one 32-byte chunk.
- `tree.merkleize(~hash, chunks)`: merkleize at the smallest perfect width.
- `tree.merkleize_limit_checked(~hash, chunks, limit)`: return `None` when the leaf count exceeds `limit`.
- `tree.merkleize_limit(~hash, chunks, limit)`: direct form for already validated input.
- `tree.zero_tree(~hash, depth)`: compute an all-zero subtree root.

Tree inputs and hash outputs must be exactly 32 bytes represented as
`List<&2, U32>`, with each value in `0..255`.

## Verify

```sh
make test
make build
./bend-merkle-example
```

Regenerate the committed vectors with only the Python standard library:

```sh
python3 tests/merkle_golden.py > tests/merkle.expected
```
